# Composio Toolkit Research

An evidence-backed research pipeline for evaluating whether 100 software products can be built as reliable AI-agent toolkits.

The project is being implemented incrementally from the specifications in [`final/`](final/). That directory is reference material and is not part of the runtime package.

## Current status

Phase 1, step 1: project scaffold only. Source data, schemas, retrieval, model calls, verification, analysis, and reporting are not implemented yet.

## Planned structure

```text
src/composio_research/  Python package
scripts/                Pipeline entry points
tests/                  Automated tests
data/                   Generated research artifacts
report/                 Generated case-study page
final/                  Read-only implementation handoff and reference code
```
